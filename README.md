# cloudfactory
https://whimsical.com/emmanuel-ahaiwe/cloudfactory-JzYy7dmh7UgS7hXxDCcc43

This repository contains a proposed AWS-based ML inference platform running on EKS/Kubernetes. Trained model artifacts are stored in Amazon S3, and GitHub Actions retrieves the pinned model artifact, packages it with the model-serving code and dependencies into a Docker image, and pushes the image to Amazon ECR. Kubernetes runs each model version as an independently scalable Deployment, while Traefik handles routing, TLS, authentication, and traffic splitting. Prometheus provides demand and service metrics, HPA scales model replicas, and Karpenter adds worker nodes when additional capacity is required. Terraform manages infrastructure, Helm provides shared Kubernetes templates, and Argo CD manages deployments through GitOps. Monitoring uses Prometheus, Grafana, Datadog, CloudWatch Logs, and OpenTelemetry, with separate model-quality checks to verify prediction behaviour. The main deployment flow is S3 → GitHub Actions → Docker → ECR → EKS, while the scaling flow is Prometheus → HPA → Kubernetes → Karpenter.
